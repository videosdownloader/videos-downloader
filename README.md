# Anik Tools — Video Downloader

A modern, free, privacy-first video downloader supporting 1800+ sites including YouTube, TikTok, Instagram, Facebook, and X.

## ✨ Features

- Download videos from 1800+ platforms
- Quality selection (4K, 2K, 1080p, 720p, 480p, 360p)
- MP3 audio extraction
- Live download progress with speed, ETA, and size
- Recent downloads history (localStorage)
- Command palette (Ctrl+K)
- Progressive Web App (PWA)
- Modern Fluent Design UI
- Fully responsive (mobile, tablet, desktop)
- AdSense-ready layout

## 🛠️ Tech Stack

- **Frontend:** HTML, Tailwind CSS, Vanilla JavaScript
- **Backend:** Node.js, Express
- **Downloader:** yt-dlp, FFmpeg
